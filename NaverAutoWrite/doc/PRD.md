# 네이버 블로그 자동 글쓰기 CLI PRD

## 🎯 핵심 정보

**목적**: 마크다운(md) 파일로 작성한 초안을 네이버 블로그 글쓰기 화면에 자동으로 입력하고 발행까지 수행하여, 로그인부터 발행까지의 수동 반복 작업을 없앤다.
**사용자**: md로 블로그 초안을 작성하는 1인 블로거·마케팅 담당자로, 네이버 블로그에 반복적으로 글을 발행하는 사용자.

> **[확정] 브라우저 자동화 스택: Playwright** — Selenium은 채택하지 않는다. Playwright는 CDP(WebSocket) 기반 통신으로 Selenium이 남기는 `$cdc_` 계열 DOM 마커를 남기지 않아 기본 탐지 흔적이 더 적고, 컨텍스트 격리·세션 상태 저장(`storage_state`) 등 이 프로젝트의 로그인 자동화 요구에 더 적합하다. 본 PRD의 모든 모듈·명령어·셀렉터는 Playwright API를 기준으로 작성한다.

## 🚶 실행 흐름

```
1. [CLI 실행: python main.py --md draft.md]
   ↓ [인자 파싱 / .env 로드 (NAVER_ID, NAVER_PW)]

2. [Playwright 브라우저 실행]
   ↓ [세션 상태 파일(storage_state.json) 존재 여부 확인]

   [세션 파일 존재] → [저장된 쿠키/로그인 상태로 컨텍스트 생성] → [8단계로 즉시 진행]
   [세션 파일 없음/만료] → [https://nid.naver.com/nidlogin.login 접속]
   ↓

3. [로그인 처리]
   - pyperclip으로 NAVER_ID 클립보드 복사 → #id 클릭 → Ctrl+V 붙여넣기
   - pyperclip으로 NAVER_PW 클립보드 복사 → #pw 클릭 → Ctrl+V 붙여넣기
   - 로그인 버튼 클릭 → 명시적 대기(로그인 후 페이지 전환 대기, 고정 sleep 미사용)
   ↓ [조건 체크: 로그인 결과 판별]

   [CAPTCHA/2단계 인증/신규기기 인증 페이지 감지] → [자동 처리 불가 안내 로그 출력 → 수동 인증 대기(헤드리스 비활성 모드 필요) → 인증 완료 시 재확인]
   [로그인 실패(아이디/비번 오류)] → [에러 로그 출력 후 종료 코드 반환하며 종료]
   [로그인 성공] → [세션 상태를 storage_state.json으로 저장] → [다음 단계]
   ↓

4. [https://blog.naver.com/{blog_id}?Redirect=Write& 로 이동]
   ↓ [#mainFrame 셀렉터 대기 후 해당 iframe으로 전환]

5. [팝업/헬프패널 정리]
   - .se-popup-button-cancel 존재 시 클릭, 없으면 무시
   - .se-help-panel-close-button 존재 시 클릭, 없으면 무시
   ↓

6. [md 파일 파싱: 제목 / 본문 / 이미지 경로 추출]
   ↓

7. [제목 입력]
   - .se-section-documentTitle 클릭 후 제목을 한 글자씩 0.03초 간격 타이핑
   ↓

8. [본문 입력]
   - .se-section-text 클릭 후 줄 단위로 줄바꿈 포함 0.03초 간격 타이핑

   [본문 중 이미지 참조 라인 발견] → [이미지 업로드 처리 후 계속 타이핑]
   [이미지 파일 미존재] → [에러 로그 출력 후 해당 이미지 건너뛰고 계속 진행]
   ↓

9. [발행 옵션 패널 열기]
   - 텍스트/role 기반 셀렉터(예: `get_by_role("button", name="발행")`)로 발행 버튼 클릭 → 카테고리/공개설정 패널 오픈
   ↓

10. [발행 옵션 확인 및 최종 발행]
    - 카테고리: 기본값(.env NAVER_CATEGORY 또는 미지정 시 에디터 기본값) 사용
    - 공개설정: 기본값(전체공개) 사용
    - 패널 내 최종 "발행" 버튼을 텍스트/role 기반 셀렉터로 클릭
    ↓ [발행 완료 확인: 발행 완료 후 이동하는 포스트 URL 또는 완료 메시지 확인]

    [발행 완료 미확인] → [에러 로그 출력 후 종료 코드 반환]
    [발행 완료 확인] → [다음 단계]
    ↓

11. [완료] → [결과 로그 출력 / 종료 코드 반환]
```

### naver_login.py

> **구현 기능:** `F002`, `F009`, `F011`

| 항목 | 내용 |
|------|------|
| **역할** | 세션 상태 재사용 우선, 필요 시 클립보드 붙여넣기 방식으로 자동 로그인 수행. 인증 챌린지(CAPTCHA/2FA) 감지 시 수동 개입 대기 |
| **입력** | NAVER_ID, NAVER_PW, `--session-file` 경로, Playwright browser/context 객체 |
| **처리 절차** | 1. `--session-file` 경로에 저장된 `storage_state.json` 존재 시 해당 상태로 브라우저 컨텍스트 생성 후 바로 반환(재로그인 생략)<br>2. 세션 파일 없음/무효 시 `https://nid.naver.com/nidlogin.login` 접속<br>3. pyperclip.copy(NAVER_ID) → `#id` 클릭 → Ctrl+V 붙여넣기<br>4. pyperclip.copy(NAVER_PW) → `#pw` 클릭 → Ctrl+V 붙여넣기<br>5. 로그인 버튼 클릭 → 명시적 대기(`wait_for_url` 또는 `wait_for_selector`, 고정 sleep 미사용)<br>6. 로그인 결과 판별: (a) 정상 이동 시 성공 (b) CAPTCHA/2단계 인증/신규기기 인증 페이지 감지 시 `--headless` 비활성 상태를 전제로 사용자 수동 인증 대기 후 재확인 (c) 아이디/비밀번호 오류 페이지 감지 시 실패<br>7. 로그인 성공 시 `context.storage_state(path=session_file)`로 세션 저장 |
| **출력/부작용** | 로그인된 브라우저 컨텍스트, 세션 상태 파일 저장, 로그인 성공/실패 결과 |
| **예외 처리** | 로그인 실패(자격증명 오류) 시 에러 로그 출력 후 이후 단계 진행 중단. 인증 챌린지 감지 시 자동 처리 불가 안내 로그 출력 후 수동 대응 대기(무한 대기 아님, 타임아웃 설정) |
