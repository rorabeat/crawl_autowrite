# NaverAutoWrite

마크다운(md) 초안 파일을 입력받아 네이버 블로그 로그인 → 글쓰기 에디터 진입 → 제목/본문/이미지 자동 입력 → 발행까지 수행하는 Python CLI 자동화 도구.

브라우저 자동화는 [Playwright for Python](https://playwright.dev/python/)을 사용한다. 로그인 세션은 `storage_state`로 재사용되어 매번 재로그인하지 않으며, CAPTCHA/2FA 등 자동 처리가 불가능한 인증 챌린지가 감지되면 headed 브라우저에서 직접 수동으로 인증을 완료할 때까지 대기한다.

## 설치

```bash
pip install -r requirements.txt
playwright install
```

## 환경 설정 (.env)

프로젝트 루트에 `.env` 파일을 만들고 아래 값을 채운다.

```env
NAVER_ID=네이버_아이디
NAVER_PW=네이버_비밀번호
NAVER_BLOG_ID=블로그_아이디
NAVER_CATEGORY=카테고리명   # 선택. 비워두면 기본 카테고리로 발행됨
```

- `NAVER_ID`, `NAVER_PW`: 필수. 네이버 로그인 자격증명.
- `NAVER_BLOG_ID`: 발행 대상 블로그 아이디. `--blog-id` CLI 인자로 실행 시마다 덮어쓸 수 있다.
- `NAVER_CATEGORY`: 선택. 지정 시 발행 옵션 패널에서 해당 카테고리를 자동 선택한다.

`.env` 파일은 `.gitignore`에 포함되어 있으므로 커밋되지 않는다.

## 실행

```bash
python main.py --md <md_파일_경로> [--blog-id <블로그_아이디>] [--headless] [--session-file <세션_파일_경로>]
```

| 인자 | 필수 | 설명 |
|------|------|------|
| `--md` | 예 | 발행할 마크다운 초안 파일 경로 |
| `--blog-id` | 아니오 | 대상 블로그 아이디. 미지정 시 `.env`의 `NAVER_BLOG_ID` 사용 |
| `--headless` | 아니오 | 헤드리스 모드로 실행. 기본값은 headed(CAPTCHA/2FA 수동 대응을 위해 브라우저 창이 보이는 상태)이므로, 최초 로그인이나 인증 챌린지 대응이 필요 없는 경우에만 사용을 권장 |
| `--session-file` | 아니오 | 세션 상태 저장 파일 경로. 기본값 `.naver_session/storage_state.json` |

예시:

```bash
python main.py --md draft.md
```

첫 실행 시 세션 파일이 없으면 자동으로 로그인을 시도하고, 성공 시 세션을 저장한다. 이후 실행부터는 저장된 세션을 재사용해 로그인 과정을 생략한다.

## md 작성 가이드

- 제목: 파일의 첫 번째 H1(`# 제목`)이 블로그 글 제목으로 사용된다.
- 본문: 제목 줄을 제외한 나머지 줄이 본문으로 입력된다.
- 이미지: `![대체텍스트](경로)` 문법을 사용한다.
  - 로컬 경로(예: `images/sample.jpg`)를 사용하면 해당 파일을 스마트에디터에 자동 업로드한다.
  - `http(s)://`로 시작하는 원격 경로는 업로드 대상에서 제외된다(로컬 이미지만 F007 대상).
  - 로컬 이미지 파일이 존재하지 않으면 에러 로그만 출력하고 해당 이미지는 건너뛴 뒤 나머지 본문 입력을 계속한다.

샘플은 저장소 루트의 `draft.md`를 참고한다.

## 트러블슈팅

### CAPTCHA / 2단계 인증(2FA) / 신규기기 인증

로그인 중 자동으로 처리할 수 없는 인증 챌린지(캡차, 2단계 인증, 신규기기 인증 등)가 감지되면 콘솔에 안내 메시지가 출력되고, 프로그램은 종료되지 않은 채 최대 5분간 대기한다. 이 시간 동안 `--headless`를 사용하지 않은 브라우저 창에서 직접 인증을 완료하면 자동으로 다음 단계로 진행된다. 제한 시간 내에 인증을 완료하지 못하면 오류와 함께 종료된다.

### 로그인 실패 (아이디/비밀번호 오류)

`.env`의 `NAVER_ID`/`NAVER_PW`가 올바른지 확인한다. 오류 메시지와 함께 0이 아닌 종료 코드를 반환한다.

### `#mainFrame`을 찾을 수 없음 / 에디터 진입 실패

`NAVER_BLOG_ID`(또는 `--blog-id`)가 실제 존재하는 블로그 아이디인지 확인한다. 네이버 블로그 서비스 구조가 변경된 경우일 수도 있다.

### 발행 완료를 확인할 수 없음

발행 버튼 클릭 후 예상된 포스트 URL 패턴(`blog.naver.com/{blog_id}/{postId}`)으로 전환되지 않으면 오류가 발생한다. 네이버 에디터의 발행 옵션 패널 구조가 변경되었을 가능성이 있으므로, 최신 상태에서 셀렉터를 재확인해야 할 수 있다.
