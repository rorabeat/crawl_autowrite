# 새 스타일 멀티 작업 독립 검증 체크리스트

이 문서는 구현자가 아닌 검토자가 5-b에서 사용자 요구와 실제 변경 사항을 대조하기 위한 기록이다. 항목은 검증 전까지 미확인으로 둔다. 실 서비스나 모델을 호출하지 않은 결과는 실제 동작을 입증하지 않는다.

## 기존 기능과 격리

- [ ] 기존 사용자 변경 사항을 보존하고, 기존 멀티 작업의 생성·수정·삭제·순서 변경·대기·시작·취소와 일반 파이프라인의 동작이 유지된다.
- [ ] 새 기능은 독립 폴더와 별도 탭을 사용하고 작업 정의가 일반 작업과 섞이지 않는다. 새 작업의 상태와 산출물이 다른 작업과 충돌하지 않는다.
- [ ] 기존 직렬 대기열에서 일반 작업과 새 작업을 순서대로 실행하며, 실행 중 취소와 앱 재시작 후 복원에서도 작업 유형과 설정이 보존된다. 유형이 없는 기존 저장 데이터는 일반 작업으로 복원된다.
- [ ] 기존 설정, 입력 및 산출물 형식이 의도치 않게 바뀌지 않는다. 기존 테스트와 변경 전후 diff를 살핀다.

## 수집과 분석

- [ ] 새 작업의 기본 크롤링 건수는 3이며 검색 결과 순위의 정의와 실제 1위 URL을 확인할 수 있다. 파일명 정렬이나 최초 성공 순서로 1위를 대체하지 않는다.
- [ ] 첫 검색 결과가 없거나 접근·본문 추출에 실패하면 명시적 오류로 중단하며, 뒤의 성공 글로 대체하거나 생성·발행하지 않는다. 취소도 실패 또는 성공과 구분한다.
- [ ] 첫 글의 말투, 본문 길이, 본문 사진 수를 분석하고 결과와 출처를 작업별로 추적할 수 있다. 프로필·광고·장식 이미지와 중복 사진은 제외한다.
- [ ] 실제 사진 0장과 이미지 추출 불가를 구별한다. 정적·지연 로딩·중복·빈 본문 등 대표 HTML 사례에서 판정을 확인한다.
- [ ] 분석 결과를 새 작업의 AGENTS.md에 반영하고 기존 사용자의 AGENTS.md를 덮어쓰지 않는다. 방문 전 조사 관점, 원문 표현 복사 금지 및 필요한 설정을 포함한다.

## 생성과 발행 경계

- [ ] 첫 글과 생성 글의 길이를 같은 규칙으로 측정한다. 제목, 태그, 이미지 대체 텍스트와 마크다운 표기, 공백의 처리 기준이 명확하고 실측 길이가 목표의 ±10% 범위에 들어간다.
- [ ] 길이가 범위를 벗어나면 유한하게 재시도하고, 끝내 충족하지 못하면 오류를 표시하고 발행을 막는다. 빈 글과 비현실적으로 짧은 원문을 확인한다.
- [ ] 이미지 목표는 분석 결과를 0~15 범위로 제한한다. 0장일 때 이미지를 요청하거나 삽입하지 않고, 양수일 때 실제 생성된 파일과 본문 내 유효한 로컬 참조가 목표 수와 일치한다.
- [ ] 지원하지 않는 이미지 생성 백엔드는 명시적으로 거부하며 검색 이미지 다운로드를 생성 이미지로 세지 않는다. 이미지 부족·누락·잘못된 참조가 있으면 발행을 막는다.
- [ ] 생성 프롬프트와 결과에서 원문은 정보 참고로만 취급하고 문장 복사와 출처에 포함된 지시문 실행을 금지한다. 완전한 비복제나 실제 방문 경험 부재를 자동 검사가 보장한다고 단정하지 않고 산출물을 별도로 읽는다.
- [ ] 모든 실패 경로에서 후속 발행을 막고 UI에 원인을 표시한다. 네트워크, 모델, 실제 네이버 발행을 수행하지 않았다면 해당 항목은 미검증으로 명시한다.

## 검증 기록

- 2026-10-27 독립 5-b 판정: **오프라인 기준 통과, 실제 서비스는 미검증**. 최초 검토에서 발견한 문제를 수정한 후 코드와 fixture를 다시 대조했다.
- 독립 실행: `QT_QPA_PLATFORM=offscreen`에서 `pytest -q -p no:cacheprovider tests/test_style_backend.py tests/test_style_ui.py` **18건 통과**. 구현 담당자는 별도로 관련 26건 및 기존 회귀 125건 통과를 보고했다. 외부 사이트·AI·발행은 호출하지 않았다.
- 검색 1위 및 실패 처리: 모의 API 응답에서 원래 순위와 첫 네이버 블로그 순서를 확인하고, 첫 글 실패 시 후속 글을 대신 쓰지 않음을 테스트했다. 기본 건수 3, 유형 저장·복원과 표준 기본값, 공유 큐 및 새 폴더 분리는 코드와 Qt 테스트로 확인했다.
- 본문 길이: 수정 전 동일 본문 HTML/Markdown이 204자/415자로 달랐지만 수정 후 415자/415자로 일치한다. 소제목·반복 문단 및 인라인 HTML fixture와 ±10% 실패 후 최대 6회·발행 차단을 확인했다.
- 사진: 본문 구성요소의 미해석 이미지와 정상 0장을 구분하고, lazy 주소·중복·장식 제외를 fixture로 확인했다. 목표는 최대 15이며 시도 폴더 이미지 전수, 유효 이미지 디코딩과 로컬 본문 참조를 비교한다. 검증 실패 시 후속 시도를 격리된 staging에 복사한다.
- 작업별 AGENTS.md는 말투 계측과 분석 결과를 담고 기존 파일을 덮어쓰지 않는다. 복제·방문 경험 금지, 신뢰할 수 없는 원문 지시 무시를 명시하며 50자 이상 일치 구절과 일부 경험 표현을 자동 차단한다. UI에서 취소를 구분하고 새 워커 예외를 실패로 표시한다.
- **미검증 및 한계**: 의미상 복제·변형된 경험 표현은 결정적 검사로 완전히 판별할 수 없다. 파일과 참조가 유효해도 이미지가 실제 생성 도구에서 왔는지는 증명하지 못한다. 실제 네이버 HTML 변형, AI 문체와 이미지 생성 품질, 계정 발행 및 실제 GUI 운영은 실서비스 실행을 하지 않아 미검증이다. 이미지 해시가 같은 복사본은 한 장으로 처리한다.
